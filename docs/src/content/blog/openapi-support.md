We've added support for embedding OpenAPI specifications directly into your documentation using the `starlight-openapi` plugin.

## What This Means

Your API documentation now lives alongside your guides and tutorials. No more maintaining separate API docs!

## Key Features

- **Swagger 2.0, OpenAPI 3.0, and 3.1** support
- **Auto-generated pages** for each API endpoint
- **Sidebar integration** with your existing documentation structure
- Supports both **local files** and **remote URLs**

## Getting Started

Simply add your OpenAPI spec file and configure the plugin in your `astro.config.mjs`. Check the [API Reference](/astro-starlight-docs-template/api/) section to see it in action.
