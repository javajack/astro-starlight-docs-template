## Why This Tool?

Building documentation is easy with Astro and Starlight. But making it **production-ready** requires implementing analytics, GDPR compliance, SEO optimization, and modern AI crawler support. This tool does all of that in one command.

## What You Get

- ✅ **Google Analytics 4** with Consent Mode v2
- ✅ **GDPR Cookie Consent** banner with Accept/Reject/Settings
- ✅ **Regional Intelligence** - Different behavior for EU vs non-EU visitors
- ✅ **SEO Meta Tags** - Open Graph, Twitter Cards, structured data
- ✅ **LLM Optimization** - AI crawler support via llms.txt
- ✅ **Custom Footer** with cookie settings and privacy notice
- ✅ **Provenance Attestations** - Cryptographically verified npm package
- ✅ **Zero Breaking Changes** - No component overrides that break layouts

## The Problem This Solves

You've built beautiful documentation with Astro and Starlight. Now you need:

1. **Analytics** to understand your users
2. **GDPR compliance** to operate legally in the EU
3. **SEO optimization** to rank in search engines
4. **AI discoverability** for ChatGPT and other LLM tools

Setting this up manually takes hours and requires:
- Understanding Google Consent Mode v2
- Implementing regional detection
- Creating cookie consent UI
- Configuring analytics properly
- Adding meta tags correctly
- Understanding GDPR requirements

**This tool does it all in under 2 minutes.**

## Quick Example

```bash
# Navigate to your Astro Starlight project
cd my-docs

# Run the optimizer
npx astro-starlight-docs-template init

# Answer a few questions
# ✓ Google Analytics ID: G-XXXXXXXXXX
# ✓ Site URL: https://example.com
# ✓ Create custom footer? Yes

# Done! Build and deploy
npm run build
```
